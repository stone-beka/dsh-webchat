# 相对官方 v0.1.1 改了什么

基线：`deepseek-ai/chat-demo` v0.1.1（MIT）。下面的改动都在 `app/` 里，`dist/` 是它的构建产物。

## 1. 标题与文案

`<title>`、左上角应用名改为 **DSH WebChat**，并补了首次使用说明、帮助与反馈两份文案（中英各一份）。品牌名保留 DeepSeek 字样只出现在说明里，应用名不写成官方产品。

## 2. 首次打开跟随宿主

页面从未保存过主题/语言时，读 iframe URL 上的 `?seed-theme=` / `?seed-locale=` 作为默认值；你在页面里手动改过之后以你的选择为准，宿主不再覆盖。

实现：`app/src/services/settings.ts` 的 `seedParam`。

## 3. 置顶（含导入修复）

- 会话 `⋯` 菜单增加「置顶 / 取消置顶」，置顶会话进侧栏最上面的「置顶」分组，不再重复出现在时间分组里。
- **导入官方导出时读取会话级 `pinned` 字段**：上游在导入时把它丢了，导出时又写回 `false`，这里补了回来（`history/schema.ts`、`history/toLocal.ts`、`history/toArchive.ts`）。
- 置顶组内顺序可手动调整，顺序记在本机 `chat-demo:pin-order`（localStorage）。官方导出格式里没有这个字段，所以不进导出。

## 4. 分支图谱（新界面）

会话右上角的树状按钮打开右侧面板，把当前会话画成「时间向下、分支向右」的树：

- 叶子槽位递增、父节点取首尾子节点中点，整棵树居中而不是贴左对齐（`app/src/components/tree/treeLayout.ts`）。
- 点任意卡片跳到该消息；不在当前分支时先用 `messagesToReveal` 逐层切回（`app/src/services/chat/revealPath.ts`）。
- 主干实线、被放弃的分支虚线；当前节点双环。
- Ctrl+滚轮以光标为锚点缩放、拖动平移、右下小地图（可点可拖）、拖左缘改宽（宽度记在 `chat-demo:branch-map-width`）。
- 卡片按角色着色（你＝深蓝、回答＝浅蓝），被放弃的分支可调暗；设置面板可切换配色、背景（纯色/渐变/点阵）、是否显示连线与小地图。

## 5. 对齐网页端使用习惯

| 功能 | 实现要点 |
|---|---|
| 搜索对话（`Ctrl+K`） | 内存索引，只重读 `updatedAt` 变化的会话；标题命中 + 消息命中（片段、角色）；**索引全部消息而非仅当前分支**，点开时先切回那条分支 |
| 多选 | 侧栏勾选态 + 批量删除/置顶/取消置顶，删除有确认 |
| 置顶排序 | 「排序」进入逐行上移/下移 |
| 导出分享 | Markdown / 单文件 HTML（内联样式、可离线打开）；官方是服务端分享链接 |
| 帮助与反馈 | 本机实例的常见问题 + 官方服务协议/隐私政策/上游项目链接 |

## 6. 首次使用说明

第一次打开弹一次介绍（这是什么 / 相对官方改了什么 / 需要知道的代价 / 安全边界），关掉之后才提示填 API Key；是否看过记在 `chat-demo:about-seen`，设置里可再看。

## 没有做、也不打算做的

分享链接托管、账号与登录设备、未成年人模式、「数据用于优化体验」开关、云端同步 —— 都依赖官方服务端，本机实例不做。
